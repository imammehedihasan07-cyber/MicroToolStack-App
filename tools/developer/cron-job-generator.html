Understanding Crontab Schedules in Linux

The cron system daemon automatically executes background shell scripts and automated tasks on Linux and Unix servers. Crontab files rely on a 5-field syntax defining the exact minute, hour, day of the month, month, and day of the week for command execution.

Cron Syntax Special Characters Guide

  • * (Asterisk) — Matches any value in the field (e.g., every minute or every hour).
  • , (Comma) — Specifies a list of values (e.g., 1,15,30).
  • - (Hyphen) — Defines a range of values (e.g., 1-5 for Monday through Friday).
  • / (Slash) — Specifies step values (e.g., */15 for every 15 minutes).

Frequently Asked Questions

Is Sunday represented by 0 or 7 in cron?

In standard Linux crontabs, Sunday can be represented by either 0 or 7.
