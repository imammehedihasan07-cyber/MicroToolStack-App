Free Image & Media Utilities

Fast, 100% private, and browser-based utilities to convert, crop, flip, rotate, and process image files effortlessly.

✂️ Image Cropper

Crop images to precise aspect ratios (1:1, 16:9, 4:3) with interactive instant preview.

🪞 Image Flipper

Flip images horizontally (mirror effect) or vertically instantly in browser.

🔄 Image Rotator

Rotate JPG, PNG, and WebP images clockwise or counter-clockwise easily.

🌟 Favicon Generator

Generate multi-size website favicons (16x16, 32x32, 180x180) from PNG or JPG images.

📦 ICO Converter

Convert PNG, JPG, or WebP images into .ICO format for website favicons and desktop icons.

🎨 Color Palette Extractor

Upload photos or designs to automatically extract dominant matching HEX color codes.

📷 EXIF Metadata Viewer

Inspect hidden EXIF camera tags, resolution, file specifications, and technical metadata.

🖼️ Base64 to Image

Decode Base64 Data URI strings back into viewable and downloadable image files.

📄 Image to Base64

Convert image files directly into Base64 Data URI strings for HTML and CSS embedding.
